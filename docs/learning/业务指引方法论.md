# 会计师事务所财政支出绩效评价业务方法论

> 提炼自《会计师事务所财政支出绩效评价业务指引》（中国注册会计师协会，7章+5附录）。
> 适用范围：会计师事务所就被评价单位的财政支出（项目支出）进行绩效评价并独立出具报告的情形；其他类型绩效评价业务可参考使用。
> 说明：本文为结构化方法论提炼，非原文转载；关键数字（文号、原则条款数、方法种类、质量要求项数、评分层级等）均已保留。

## 〇、业务总纲

### 业务定位
- 会计师事务所作为**第三方**独立开展项目支出绩效评价：接受财政或预算部门委托，运用科学规范的评价方法，将项目投入产出的实际情况与评价标准、评价依据比较分析和综合评判，形成评价结论、出具评价报告，并通过评价发现决策和执行中的问题、提出改进方向，以促进预算管理。
- 若财政部门对绩效评价组织管理和工作程序已有要求，事务所须遵守相关要求。

### 评价对象与范围
- 对象：纳入政府预算管理的资金。按预算级次分为**本级部门预算管理资金**与**上级政府对下级政府的转移支付资金**。
- 部门预算支出绩效评价分为：**基本支出绩效评价、项目支出绩效评价、部门整体支出绩效评价**。以**项目支出**为重点，评价一定金额以上、与部门职能密切相关、具有明显社会影响和经济影响的项目；有条件的地方可对部门整体支出进行评价。

### 绩效评价的"3E"（核心评价维度）
1. **经济性**（成本 vs 投入）：以最低费用取得一定数量和质量的资源，即预算支出是否节约。考量：投入方式/设备是否对公共资金最经济使用；人财物是否被经济使用；管理活动是否符合良好管理原则和政策。
2. **效率性**（投入 vs 产出）：以最小投入取得一定产出，或以一定投入取得最大产出。可通过与类似活动、其他期间、已采纳标准或最佳实践比较得出结论；无法比较时依据所获信息、观点及分析进行评价。考量：资源是否有效运用；项目/实体/活动是否被有效管理组织执行监控评价；支出是否符合规定目标和要求；公共服务是否以服务对象为导向并及时提供；是否有效实现项目目标。
3. **效益性**（产出 vs 目标）：达到政策目标、运营目标和其他预期结果的程度。考量：经济效益、社会效益、生态效益、可持续影响、社会公众或服务对象满意度；识别阻碍绩效目标实现的因素；识别公共服务更合理的途径并分析结果与原因。

### 绩效评价的基本内容（5项）
1. 绩效目标设定情况；
2. 资金投入和使用情况；
3. 为实现绩效目标制定的制度、采取的措施等；
4. 绩效目标的实现程度及效果；
5. 绩效评价的其他内容。

### 绩效评价的基本原则（4条）
1. **科学规范原则**：严格执行规定程序，定量与定性分析相结合；
2. **公正公开原则**：真实、客观、公正，依法公开并接受监督；
3. **分级分类原则**：由各级财政部门、各预算部门按评价对象特点分类组织实施；
4. **绩效相关原则**：针对具体支出及其产出绩效，评价结果清晰反映支出与产出绩效的紧密对应关系。

### 绩效评价的主要依据（8类）
1. 国家相关法律、法规和规章制度；
2. 各级政府制定的国民经济与社会发展规划、方针政策和相关制度；
3. 预算管理制度、资金及财务管理办法、财务会计资料；
4. 预算部门职能职责、中长期发展规划及年度工作计划；
5. 相关行业政策、行业标准及专业技术规范；
6. 申请预算时提出的绩效目标及其他相关材料，财政部门预算批复，财政部门和预算部门年度预算执行情况，年度决算报告；
7. 人大审查结果报告、审计报告及决定、财政监督检查报告；
8. 其他相关资料。

## 一、业务流程阶段划分（4大阶段 + 结果运用环节）

### 阶段一：业务承接

**目标**
- 确定是否具备承接前提、明确各方责任、以书面协议固化委托关系，为后续评价奠定合同与责任基础。

**前置条件（承接绩效评价业务的三大前提）**
1. **被评价单位认可并理解其责任**。被评价单位责任包括：①设定、确认绩效目标；②设计和实施恰当的内部控制（含预算管理制度），保证经济、有效、合法使用预算资金；③根据绩效目标完成情况填列基础信息表、汇总相关情况和数据、提供佐证资料、总结分析并编制绩效报告；④及时提供必要工作条件（提供真实、合法、完整基础资料，允许评价人员不受限制接触所需信息）。
2. **绩效评价工作组具有专业胜任能力**。人员需受过良好教育、具有学历和工作经验、足够专业熟练程度与工作能力，具备逻辑归纳、社会调查、写作、交流沟通能力（学习创新、社交技巧、诚实公正、判断力、承受压力、口头表达与书面沟通）。团队需具备的知识技能：①绩效评价知识及职业判断能力和经验；②政府组织、职能和项目相关知识；③预算管理、项目管理和财务管理专业知识及应用；④公共部门管理、财务会计、管理会计、统计、工程造价、信息技术、审计、咨询、管理学、社会调查等专业技能应用能力。
3. **绩效评价人员遵守职业道德要求**（详见第四部分职业道德与独立性）。

**具体操作步骤**
1. 评估被评价单位是否认可并理解其责任；
2. 评估工作组专业胜任能力并组建/委派人员；
3. 确认人员遵守职业道德要求，设置回避制度与程序；
4. 决定承接后，与委托方就业务约定条款达成一致，形成绩效评价服务合同或其他适当形式书面协议（条款包括：评价对象和内容、各方责任、业务收费、合同终止条款、违约责任等）；
5. 根据业务具体情况确定委派人员级别、时间及聘用专家等投入，与委托方协商合理收费。

**所需资料/参考文件**
- 附录一《绩效评价服务合同参考格式》。

**与其他方沟通协调事项**
- 与被评价单位的沟通始于初次接触；将评价目标和方法告知被评价单位，争取协助，建立建设性互动；
- 关注评价过程中的沟通与反馈：评价可能遇到被评价单位消极对待，评价人员需与相关方面及时信息反馈。

**阶段性成果/底稿**
- 绩效评价服务合同/业务约定书（书面协议）。

### 阶段二：计划评价工作和编制评价工作方案

**目标**
- 合理计划评价工作，及时、经济、高效完成评价；通过调研编制审慎的评价工作方案，作为具体实施的基础与质量保障手段。

**前置条件**
- 已完成业务承接、明确评价对象与委托要求；
- 已初步了解项目基本情况（通常需先行调研）。

**方案三原则与五要素**
- 三原则：**可行性**（符合主客观条件，内容、方法、步骤、时间节点科学合理可操作）、**全面性**（全面反映评价对象、范围、步骤、方法、时间、组织实施，明确指标体系和数据采集方法来源）、**简明性**（逻辑性强、简明扼要、易于理解）。
- 五要素：**项目概况、评价思路、指标体系、社会调查、组织实施**。

**具体操作步骤**
1. **开展调研**，充分了解被评价项目/单位业务情况：
   - 调研内容（6项）：项目特点（经济分类、角色职能、常规行为和过程、发展趋势）；项目总体目标和绩效目标；组织结构和受托责任关系；内外部环境及利益相关方；影响项目实施的外部制约因素；管理制度、岗位责任制度和资源保障程度。
   - 信息来源（9项）：相关立法和立法机关报告；部门相关政策文件；单位组织结构、内部管理文件和操作手册；行业调查及专家研究观点、现场踏勘；预算资金支出合规性检查和专项业务调查结果；与被评价单位和利益相关方讨论结果；管理信息系统；新闻报道；其他相关信息系统（如办公统计数据）。
   - 项目信息（3类）：①**项目决策**（查阅国民经济与社会发展规划、方针政策、行业政策/标准/规范、可行性研究报告、立项报告、财政批准预算方案、单位工作计划和职能文件）；②**项目管理**（查阅实施方案、招投标文件、工程监理报告、财务管理制度、项目账簿、专项审计报告等）；③**项目绩效**（查阅完工验收报告、项目经费决算表、预算单位绩效报告及项目执行情况报告等）。
2. **设计绩效评价指标体系**（详见第二部分指标体系设计要点）：
   - 指标（共性+个性，5原则）；
   - 评价标准（计划标准、行业标准、历史标准、其他经财政部门确认的标准）；
   - 指标权重（从投入、过程、产出、效果四方面构建，提高产出类、效果类指标权重使其占主导）。
3. **确定绩效评价方法**（5种，详见第二部分评价方法）。
4. **委派评价人员**：
   - 指定业务负责人，对具体绩效评价业务总体质量负责；
   - 考虑人员胜任能力，确信工作组整体具有适当胜任能力并遵循职业道德要求；
   - 合理安排分工：业务负责人指导、监督、复核成员工作，确保成员充分理解评价目标、评价程序充分且恰当执行、评价资料充分可靠相关并得以记录、满足预算/时间表/方案安排要求、与委托方和被评价单位充分沟通及时征求意见；可安排经验较多人员复核经验较少人员工作，合理保证疑难问题适当咨询。
5. **利用专家工作的特殊考虑**：
   - 专家工作两类：**专家咨询**（借专家专业力量为专业问题提供意见建议，评价人员据此作结论）与**专家评审**（专家直接参与评价、对3E作判断，评价人员整理专家意见形成报告）；
   - 考虑聘任条件（胜任能力和经验；遵守财政部门专家聘任具体要求；可借助财政部门绩效评价专家库）；
   - 明确专家定位（确保专家独立于被评价项目，告知道德规范如保密与回避要求，以专家承诺书确认；指定专人加强沟通、尊重采纳专家恰当意见）。
6. **编写评价工作方案**：
   - 符合可行性、全面性、简明性要求；
   - 业务负责人和工作组成员共同参与制定（必要时委托方、评价人员、专家等多方参与沟通；依财政部门要求可能需评审或财政部门认可）；
   - **时间要求**：在业务约定书约定时间内完成方案（初稿），在委托方组织方案评审会后的约定时间内提交方案（正式稿）。

**工作方案的结构与内容（详见附录二参考提纲）**
- 项目概况：①立项背景和目的；②立项依据（逐条列示、注明出处）；③项目预算及资金来源（含预算变更及原因、资金计划安排）；④项目计划实施内容（立项时间、批复单位、具体内容、所在区域、资金投向、计划完成时间）；⑤项目组织及管理（主管部门/实施单位职责、管理架构、实施流程、业务和财务管理制度）；⑥利益相关方（主管部门、项目单位、项目受益者、社会公众，分析其参与设计实施运行受益路径及职责作用）；⑦项目绩效目标（与立项目的相关性合理性、设立依据、实际设定情况）。
- 评价思路：①评价目的和依据；②评价对象和范围；③评价时段的确定。
- 绩效评价指标体系：总体思路、指标体系（共性+个性，按决策类/管理类/绩效类分级）、各项指标定义/评分标准/评分细则。
- 社会调查工作方案：调查目的、调查对象、调查方式、抽样方法、问卷内容、访谈提纲。
- 评价的组织实施：①工作组人员分工；②评价时间及主要工作进程安排；③质量控制制度。

**与其他方沟通协调事项**
- 方案确定可能需要委托方、评价人员、专家等多方参与沟通；
- 依财政部门要求，方案可能需经适当形式评审或财政部门认可；
- 与被评价单位管理人员沟通了解项目管理、预算资金管理及使用情况。

**阶段性成果/底稿**
- 绩效评价工作方案（初稿/正式稿）；
- 绩效评价指标底稿（指标解释、权重、评价标准、数据来源及取数方式）；
- 社会调查工作方案（问卷、访谈提纲）。

### 阶段三：绩效评价的具体实施

**目标**
- 通过资料收集、分析和持续沟通，充分收集定性与定量信息，描述、分析绩效目标实现程度，直至支撑最终评价结论。

**前置条件**
- 评价工作方案已确定（可能已通过评审/获财政部门认可）；
- 已获得被评价单位提供资料清单所列资料。

**具体操作步骤**
1. **收集资料**（核心工作，按预算管理程序、项目管理要素和绩效评价工作要求有序全面收集，6大类）：
   1. 相关评价标准（法律法规、政策文件、行业标准及专业技术规范）；
   2. 项目立项资料（调查报告、可行性研究报告、立项或概算批复、预算批复）；
   3. 项目管理资料（管理制度与责任制度、财务管理制度）；
   4. 预算决算资料（预算申报表、决算报表及相关会计资料）；
   5. 项目实施资料（招投标文件、委托外包合同或计划任务书、监理报告、审价报告、审计报告）；
   6. 产出效果资料（项目成果及交接资料、专业验收报告、项目总结资料、社会调查资料及受益者问卷调查）。
   - 针对项目具体情况编制"提供资料清单"交预算单位或实施单位准备并要求及时提供；
   - 对项目资金投入、委托外包程序和经济合同执行情况，对照财经法规进行**合规性检查**，作为项目投入与项目管理的重要评价资料。
2. **选用资料收集方法**（7种，详见第二部分证据收集方法）。
3. **整理判断**：秉持批判态度"去粗存精、去伪存真、由此及彼、由表及里"；区分一手数据（自有资料：问卷、调查、观察）与二手数据（他人提供，绩效评价中大量使用）；过于苛求数据精确性可能高成本且不必要，次优方案数据可能已充分适当；信息系统生成的信息需评估信息系统可靠性（审查一般控制和应用控制）；获取敏感性信息（如对管理层看法）需确保匿名、不泄露信息提供者身份。
4. **综合分析**：
   - **定量分析**：①了解数据分布与变化（结构性/趋势性图表；关注"集中趋势"、数据分布范围、数据分布形态三种分布，用于确定数据水平/范围/形态、通过概率分布评价风险、评估样本能否代表总体）；②回归分析（确定变量相关关系、识别异常事件、预测未来数值）。
   - **定性分析**：智力性、创造性、循环往复过程，包括讨论思考、头脑风暴法及内容分析、比较分析、专家小组帮助下的分析等非定量技术。
5. **信息技术环境下的特殊考虑**：
   - 系统评价环节：了解信息系统对评价目标的重要性→评价系统设计合理性、运行有效性、一般控制与应用控制适当性，确定评价范围与内容，聘请信息系统专家→视需要开发运用计算机辅助评价技术。
   - 需要考虑的问题：信息系统范围内容业务流程和潜在风险；是否支持单位目标和经营战略；运行需高素质员工；用业务效率指标衡量信息系统贡献；信息技术对透明、问责机制和治理的贡献。
   - 计划评价工作：纳入评价工作方案，配备训练有素人员，获取适当软硬件工具，适当培训；技术性强领域可能需专家。
   - 计算机辅助评价技术运用（7项）：访问提取被评价单位数据库信息；加总概括分类比较或按标准抽取大量数据；制表核对计算；抽样统计处理分析；帮助完成评价方案和控制（电子工作底稿、有效索引、复核和报告）；开展网络问卷调查；提供满足特定评价要求的报告。

**工作重点**
- 资料质量三特征（充分性、可靠性、相关性）——详见第二部分；
- 资料收集方法的选择遵循灵活务实原则，关注方法的**有效性**（方法与评价目标相适应）和**可靠性**（同一环境重复调查能得出一致结论）；
- 合规性检查、信息系统可靠性评估、敏感信息匿名保护。

**与其他方沟通协调事项**
- 与委托方和被评价单位持续沟通，就各种发现、意见和观点进行评价；
- 当形成的是说服性而非结论性资料时，及时与相关专家讨论其性质，降低误解风险、加快进度；
- 被评价单位及有利害关系当事人可能提出不同观点，评价人员需从不同来源及时收集资料、分别沟通。

**阶段性成果/底稿**
- 资料收集记录与"提供资料清单"；
- 各类证据（实物、口头、书面、分析性资料）；
- 数据分布/回归分析结果、定性分析记录；
- 访谈记录、座谈会记录、问卷汇总、观察记录。

### 阶段四：形成评价结论和撰写评价报告

**目标**
- 汇总分析所获信息，形成评价结论，撰写并分发绩效评价报告。

**具体操作步骤（形成结论时需进行的6项工作）**
1. **获取书面声明**：向被评价单位获取其已履行编制绩效报告和提供完整信息责任的书面声明（附录四参考格式，内容据项目实际调整）。
2. **复核评价资料**：考虑资料是否充分、可靠、相关；要求被评价单位提供尽可能全面的项目资料，同时利用各种公开统计数据（政务公开信息、统计或研究机构数据库及研究成果、互联网数据信息），形成宏观与微观层面的数据信息支撑。
3. **形成评价结论**：系统谨慎分析所收集资料和意见，核对细节问题、权衡各种观点、向专家咨询、比较分析；将评价结果按既定要求组织，在工作组内外部讨论。结论要说明绩效目标实现程度，用绩效指标完成情况反映投入、产出、效果方面的成绩经验与问题，对指标目标值与实际值差异、产生原因与预期后果具体分析；尽量涵盖所有可能预见的主要观点（利用经验丰富专家帮助权衡对立观点），避免最终阶段出现全新决定性观点。
4. **梳理问题与建议**：建议以事实为依据、具体可行；分析问题原因和结果作为建议基础；可对项目设立必要性、项目设计科学性、预算资金投入合理性、项目管理和资金管理内部控制保障度等提出政策建议；改进措施应合理可操作、有利于提高预算绩效管理。
5. **与被评价单位充分沟通**：出具正式报告前多方面沟通，对问题表述征询意见（非干涉职业判断，而是获取解释和补充资料以确认问题性质和影响）；评估被评价单位反馈信息，符合评价资料一般标准则修改报告；恰当记录口头或书面反馈并分析所有意见分歧。
6. **征询监管部门和专家意见**：可将报告初稿提交相关专家、财政部门及主管部门沟通，获取建议，考虑是否改进报告。按《财政支出绩效评价管理暂行办法》，**绩效评价结果采取评分与评级相结合的形式**，实务中执行财政部门对分值和等级的规定。

**撰写评价报告（7部分内容，详见附录五参考提纲）**
1. **项目概况**：项目单位基本情况、项目实际实施情况、资金来源和使用情况、设定的绩效目标；
2. **绩效评价的组织实施情况**：评价人员构成、数据收集方法、评价具体实施过程；
3. **绩效评价指标体系、评价标准和评价方法**：指标设定及权重、具体评价标准；
4. **绩效目标的实现程度**：项目产出与效果、完成预期产出的数量、实现预期质量的标准水平、达到预期进度时效、对照预期效益指标分析实现程度；
5. **存在问题与原因分析**：分析指标目标值与实际值差异，从项目决策、实施、管理等主要方面描述问题，分析原因及预期影响；
6. **评价结论及建议**：按评价标准（评分值、等级、分类评分结果）阐述评价结果，反映成绩经验、披露问题、提出切实可行改进建议和措施；
7. **其他需要说明的问题**：各地财政部门对报告格式和内容的进一步规范要求。

**报告质量要求（7项）**
1. **充分性**：各部分内容有足够依据，资料来源清晰，引文注释，指标评价有工作底稿，社会调查有工作记录；
2. **完整性**：包含实现评价目标所需的全部信息和观点，评价目标、标准、发现和结论之间关系可证实、完整、清晰，建议与分析结果/结论有清晰联系；
3. **准确性**：报告可信可靠，不准确之处会令使用者质疑整份报告并损害事务所及行业信誉；
4. **透彻性**：全面阐述绩效目标实现程度，对3E作具体分析，因果分析清晰透彻；
5. **逻辑性**：易于阅读理解、结构顺畅、组织合理，定量与定性结论一致，内容不重复，文句严谨，术语和不常用缩写诠释涵义；
6. **客观性**：内容表述公正，避免夸大或弱化绩效不足，事实与意见分开陈述，语言不带偏见或暗示；
7. **及时性**：在方案（正式稿）通过后的约定时间内完成报告（初稿），在委托方组织报告评审会后的约定时间内提交报告（正式稿）。

**报告的分发和使用**
- 遵守财政部门相关规定及业务约定书要求；
- 绩效评价结果公开披露已在部分地区试点（政府网站公布），促进社会监督。

**阶段性成果/底稿**
- 被评价单位声明书（书面声明）；
- 绩效评价报告（初稿/正式稿）；
- 反馈意见记录、意见分歧分析记录。

### 阶段五：评价结果反馈与运用（依流程图示例，多为委托方/主管部门职责）

## 二、证据收集方法（原文共7种，含适用场景与操作要点）

> 说明：任务书称"6种证据收集方法"，但原文《第四章 一、资料收集方法》实际列出**7种**（文件检查、文献分析、问卷调查、访谈、研讨会、焦点小组、观察），并有"资料收集方法比较表"对其中5种（问卷调查、访谈、文件检查、观察、焦点小组）作优劣对比。本文按原文完整收录7种。

1. **文件检查**
   - 适用场景：收集资料的有效途径，可提供项目绩效（总结）报告、项目受益者满意度测试、政府相关优惠政策规定等；对会计资料反映的预算资金收支活动进行合规性检查（项目独立核算、专款专用、原始凭证合规、资金收支合法）。
   - 操作要点：在绩效评价**初期**需确定文件的性质、地点及可获得性，确保成本效益性。
   - 比较表要点：优势——反映全面历史信息、不干扰项目或客户日常工作、信息已存在、很少对信息有偏见；不足——常花费很多时间、信息可能不完整、需清楚在寻找什么、不是获取数据的灵活方法（仅限于已存在的数据）。

2. **文献分析**
   - 适用场景：查阅与评价业务相关的文献、研究相关历史资料，帮助获取有用资料。
   - 操作要点：需对文献内容可靠性进行评估，包括信息是否客观、是否多方位描述。

3. **问卷调查**
   - 适用场景：从人群或组织群体中收集详细、具体信息，特别是就某个特定问题收集信息。
   - 操作要点：可运用函证、网上调查、电话核实等多种调查方法；通常需计算机加工；假定对问题内容有较好了解；合理使用则有效，但设计问卷和处理答复较为困难、耗时。
   - 比较表要点：优势——可匿名完成、管理成本较低、易于比较分析、可获得大量数据、许多样本问卷可供使用；不足——可能得不到认真反馈、措辞可能影响回应、需要抽样方面专家、无法给出全貌。

4. **访谈**
   - 适用场景：绩效评价大量依赖访谈，用于计划阶段及调查阶段，获取与评价目标相关的文件、意见和想法，证实其他渠道获取的事实和数据。
   - 操作要点：不同阶段进行不同类型访谈——从非结构化（开放式询问）到结构化（封闭式问题清单）；可访谈一人或多人；需对不同职位、观点、见解的人员访谈以广泛获取信息；**访谈前需策划**；对结果进行整理和记录以帮助后续分析和质量复核；分析时需将谈话内容分为不同类别或主题，归纳共同线索或相互印证事项。
   - 比较表要点：优势——获取全面深入信息、建立关系、灵活沟通；不足——需要较长时间、难以分析和比较、成本很高、采访者可能影响受访者回应。

5. **研讨会**
   - 适用场景：绩效评价各阶段均可召开；用于①获取对某专业领域的了解；②讨论项目管理的成功经验与成绩、产出与效果以及改进措施；③通报不同观点和意见。
   - 操作要点：优势在于将拥有不同知识和观点的人员聚集在一起，从而更好地了解问题领域。

6. **焦点小组**
   - 适用场景：将选定人员集中讨论某个主题或事项，主要用于收集**定性信息**，从受益人或其他利益相关方获取执行情况信息及政府项目影响信息。
   - 比较表要点：优势——快捷可靠获取共同印象、短期内获取广泛深入信息的有效方法、能传达项目关键信息；不足——难以分析成员反应、协调员需负责保密和披露事宜、很难将多人安排到一起。

7. **观察**
   - 适用场景：绩效评价中**并不常见**；主要用于深入了解操作的运行方式，获得相关领域人员的意见、测试观点及与其他信息对比。
   - 比较表要点：优势——观察项目实际发生情况、灵活应对发生事项；不足——解释观察到的行为存在困难、对观察活动分类复杂、可能影响被观察者行为、成本较高。

### 资料收集方法的有效性/可靠性
- 选择方法基本原则：**灵活务实**；某些实际情况（如数据可获得性）可能限制可选方法，评价人员可能不得不选择次优方案。
- 有效性：采用的方法与评价目标相适应；
- 可靠性：在同一环境下重复调查工作能得出一致的结论。

## 三、资料类型与质量特征（证据判断标准）

### 资料类型（4种）
1. **实物资料**：通过观察人员、事件或检查实物形成，以照片等方式呈现（实物照片比文字描述更有证明力）。实地观察实物状况对评价目标重要时需确证——可由两名或多名评价人员实地观察，如可能由被评价单位人员陪同。
2. **口头资料**：询问访谈形成的记录，可提供其他方式不易获取的重要线索（对象含被评价单位人员、项目受益人、专家、社会公众）。若不仅用于背景信息则需佐证，佐证方法：①向受访者获取书面确认书；②从多个不同独立来源证明同一事实；③检查相关记录。评估可靠性和相关性时需评估受访者可信度（职位、知识、技术、诚信）。
3. **书面资料**：绩效评价资料中**最为普遍**。外部（信件/备忘录、供应商发票、租约、合同、外部审计报告、内部审计报告和其他报告、第三方确认函）与内部（会计记录、职位描述、计划、预算、内部报告和备忘录、绩效统计汇总表、内部政策和流程）。若使用被评价单位管理控制系统（如会计系统）生成的文档，需评估系统的内部控制。
4. **分析性资料**：来自对数据资料的分析和验证（计算复核、比率分析、趋势分析、与既定标准或行业基准的对比分析）。定量（如投入产出比率）或定性（如投诉是否呈现一致趋势）。

### 资料质量特征（3项）
1. **充分性**（与资料数量相关）：影响因素——形成不恰当评价结论的风险；以往对被评价单位记录/声明可靠性的经验；被评价单位对某些事项的敏感性；获取资料的成本与其证明作用。
2. **可靠性**（真实反映应表达内容即合法可靠）：考量——佐证是增加可靠性的有效方法（从不同来源获取不同类型资料）；外部资料通常比内部资料更可靠；书面资料通常比口头资料更可靠；评价人员观察分析产生的资料通常比间接获取的更可靠；被评价单位信息可靠性一定程度上取决于其内部控制可靠性；得到书面佐证的口头资料比单独口头资料更可靠；原件比复印件更可靠。
3. **相关性**：要求资料与评价目标和标准之间具有清晰逻辑关系；制定资料收集计划时针对每个问题和标准列示所需资料的性质、来源及相关评价程序。

## 四、绩效评价指标体系设计要点

### 指标（共性 + 个性，确定指标5原则）
1. **相关性**：与绩效目标有直接联系，恰当反映目标实现程度；
2. **重要性**：优先使用最具代表性、最能反映评价要求的核心指标；
3. **可比性**：对同类评价对象设定共性指标，便于结果相互比较；
4. **系统性**：定量指标与定性指标结合，系统反映社会效益、经济效益、环境效益和可持续影响；
5. **经济性**：通俗易懂、简便易行，数据获取考虑现实条件和可操作性，符合成本效益原则。
- 共性指标：适用于所有评价对象（预算编制和执行情况、财务管理状况、资产配置/使用/处置及收益管理情况、社会效益、经济效益等），可从财预〔2013〕53号《预算绩效评价共性指标体系框架》灵活选取。
- 个性指标：针对预算部门或项目特点设定，需结合评价对象具体情况、参照财政部门规定、在与委托单位充分沟通基础上构建。
- 对于特定支出类别（经济建设、财政支农、教育、科技、文化体育、卫生、社会保障、政府采购、信息系统建设及运行维护支出等），若财政及相关部门已制定针对性绩效评价指标，须予以应用。
- 可量化指标→计算分析得出评价结果；无法量化的定性指标→专家经验判断、问卷测试、横向比较等方法取得判断依据；预算资金使用中的违规行为须充分考虑其对绩效评价等级的影响。

### 评价标准（4类）
1. **计划标准**：以预先制定的目标、计划、预算、定额等数据为评价标准；
2. **行业标准**：参照国家公布的行业指标数据制定；
3. **历史标准**：参照同类指标历史数据制定；
4. **其他经财政部门确认的标准**。
- 实务中确定评价标准可能考虑的因素：相关法律法规；立法机关或行政部门的决定；与历史信息、行业标杆值、最佳实践的比较；国家或国际相关标准；被评价单位设定个性绩效指标的合理性；专家建议；相关专业政策与知识；类似评价中使用过的标准；相关预算管理、项目管理和财务管理文献。

### 指标权重
- 权重指某指标在整个指标体系中的比重，据重要程度选用科学方法合理设置；
- 指标体系一般从预算资金的**投入、过程、产出、效果**四方面构建；
- 关注重点是实际产出和效果，故应**提高产出类指标和效果类指标的权重**，使其在整体权重中占主导。

### 评价方法（5种）
1. **成本效益分析法**：将一定时期内支出与效益对比分析，评价绩效目标实现程度；适用于成本和效益都能准确计量的项目（如公共工程项目），一般以社会效益为主的支出项目不宜采用。
2. **比较分析法**（比较法）：对绩效目标与实施效果、历史与当期情况、不同部门和地区同类支出进行比较，综合分析实现程度；主要适用于财政项目资金管理，通常也通过案例对比分析评判。
3. **因素分析法**：综合分析影响绩效目标实现、实施效果的内外因素，评价实现程度；许多支出项目运用此法，通过不同因素权重评比综合分析。
4. **最低成本法**：对效益确定但不易计量的多个同类对象的实施成本进行比较，评价实现程度；使用时需明确不同对象的产出和结果，并适当选取其他方式综合进行绩效评价。
5. **公众评判法**：通过专家评估、公众问卷及抽样调查等对财政支出效果评判；用于无法直接用指标计量效益的支出项目，可选专家评估并对社会公众问卷调查，可用于公共部门和财政投资兴建的公共设施评价。
- 选用原则：**简便有效**，据评价对象具体情况可采用一种或多种方法。

## 五、质量控制要求（原文情况与要点）

> **重要说明**：原文**未使用"三级复核"表述，也未逐级列示"项目负责人→部门负责人→主任会计师"三级复核流程**。原文对质量控制的规定是：援引《质量控制准则第5101号——会计师事务所对执行财务报表审计和审阅、其他鉴证和相关服务业务实施的质量控制》，要求事务所建立和保持相关质量控制制度，合理保证事务所和评价工作组遵守质量控制制度和相关规定、出具适合具体情况的评价报告。复核的层级要求在原文中体现为工作底稿内在的多级复核安排（见下）。若业务需"三级复核"，其具体层级与责任以《质量控制准则第5101号》及事务所内部制度为准，本文不虚构原文未载明的内容。

### 原文体现的复核安排
1. **业务负责人层级**：业务负责人指导、监督、复核工作组成员执行的评价工作（指定业务负责人对具体绩效评价业务的总体质量负责）。
2. **组内层级复核**：可安排工作组内经验较多人员复核经验较少人员的工作，并合理保证评价人员就疑难问题进行适当咨询。
3. **资料复核**：形成评价结论前复核评价资料（考虑充分性、可靠性、相关性）。
4. **报告审核**：依流程图示例，报告提交前经"审核评价报告"环节（多为委托方/主管部门组织）。

### 质量控制制度四方面（事务所层面）
1. **人力资源**：通过充分有效培训保持专业熟练程度（培训主题可含绩效评价方法发展现状、定性分析方法、案例分析、统计抽样、数据资料收集技巧、数据分析、报告撰写，以及公共管理、公共政策、社会科学或信息技术等）；视需要组织参加财政部门、注协等组织的绩效评价业务培训；在招聘、任务委派、职业发展、培训、业绩考核等方面作出合理安排。
2. **技术支持**：所内建设绩效评价技术支持平台，严格绩效评价工作质量考核。
3. **工作底稿和档案管理**：
   - 工作底稿是绩效评价中收集和产生的相关文档，包括评价工作方案、绩效指标评分工作底稿、座谈会和访谈会议记录、满意度测试汇总底稿、专家意见和建议以及评价报告等；
   - 底稿是外勤工作和评价报告的联结点，足够完整具体的底稿作用：①确认和支持评价人员的观点和报告；②提高评价工作效率效果；③作为撰写报告或回答提问的依据；④作为评价人员遵守技术规范的证据；⑤有助于工作的计划、监督和复核；⑥为未来工作提供参考依据；
   - 需对底稿的归档时间、保存期限、使用和保密作出规定，满足财政部门相关要求。
4. **信息化**：提升信息化建设水平，建立绩效评价数据库（法律法规、部门规章、指标体系、报告和底稿范本、分类专家库等），提高评价科学性和规范化。

## 六、职业道德和独立性要求

### 职业道德要求（承接前提条件之三）
- 恪守诚信、保持良好职业行为，坚持客观公正原则、保持职业怀疑态度、严格履行保密义务。

1. **客观公正原则**
   - 公正处事、实事求是，不应因偏见、利益冲突或他人不当影响而损害职业判断；
   - 委派评价人员时应考虑其是否与被评价单位存在利害关系或可能影响公正性的其他情况，在事务所内部设置相应的**回避制度和程序**，避免对客观公正性产生影响；
   - 评价人员不得向被评价单位索取、收受合同约定以外的酬金或其他财物，或利用业务之便谋取其他不正当利益。

2. **职业怀疑态度**
   - 评价人员在整个评价过程中保持职业怀疑态度，充分关注绩效评价资料的质量。

3. **保密义务**
   - 对绩效评价工作中获知的信息保密，未经适当授权或法律法规允许，不得向不相关的其他方透露，或利用获知信息为自己或他人谋取利益；
   - 对委托方在业务约定书及其他沟通文件中明确的专门保密要求，工作组需专门设置适当程序以履行具体保密条款要求。

### 独立性相关要求
- **评价人员独立性**：通过回避制度和程序防止利害关系影响客观公正（见客观公正原则）。
- **专家独立性**：确保专家独立于被评价项目，告知专家所需遵守的道德规范（保密性要求、回避要求等），并以专家承诺书等方式确认。
- **敏感信息保护**：获取敏感性信息（如对管理层的看法）时确保匿名，不泄露信息提供者身份。
- **合同层面**（附录一）：乙方（事务所）应独立完成评价项目，未经甲方同意不得转包、分包给第三人；应对评价项目内容履行保密义务，未经甲方同意不得将项目成果及评价过程资料向不相关的其他方透露，也不得用于合同之外任何目的；乙方在评价过程中应具有良好职业操守、保持独立客观公正。
