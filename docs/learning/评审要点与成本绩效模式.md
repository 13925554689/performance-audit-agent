# 评审要点与成本绩效模式

> 来源：《2025年区级财政重点绩效评价方案评审意见反馈（河南忠正）》《中国财经报·绩效新时代·河南省推进成本预算绩效管理改革纪实》及成本绩效培训案例清单。

---

## 一、绩效评价方案的质量评审要点（方案常见缺陷清单）

第三方机构"惠商保"保险保障项目评价方案评审中，专家指出的典型缺陷（可迁移为方案通用自查清单）：

1. **背景与目的不完整**：未分层级介绍国家级→省级→市级→区级背景资料，未引出项目实施目的，未说明实施起始年份、每期涉及资金及实施情况。
2. **立项依据零散**：未分点列清项目各层级依据文件。
3. **政策项目要素缺失**：未介绍清楚政策的内容、标准、范围、主体、程序、实施周期、保险期间；未交代当期具体实施情况（参保单位、保险及理赔情况）。
4. **预算及资金用途要素缺**：缺少财政资金下达文号、下达时间、资金层级。
5. **资金使用情况不具体**：缺少资金支付单位、支付时间、支付程序。
6. **项目管理跑题**：介绍的是主管部门（市监局股室）的全部职能，而非该项目本身的具体管理。
7. **利益相关方遗漏**：缺少保险公司、个体工商户等关键相关方。
8. **目标梳理不准确**：总体目标、阶段性目标未根据项目内容重新梳理，阶段性目标未以文字表述提炼。
9. **评价方向与侧重点失焦**：未侧重政策实施效果、后续政策实施及改善。
10. **绩效指标质量问题**：指标评分标准表述错误（如"资金使用合规性""制度执行有效性"等表述有误）；产出指标缺项目特色指标（政策知晓率、应保尽保率、赔付精准度、保险支付及时性、赔付及时性、成本控制情况、赔付支持情况）；效益指标、可持续指标冗余需精减精准梳理。
11. **样本抽样不可实施**：仅给样本量（200户），未说明如何覆盖核心/扩展/潜在/对比客户、如何筛选，无法保证抽样可实施。
12. **硬伤错误**：时间错误等基础性错误。
13. **质量控制措施冗长**：需精减。
14. **缺绩效指标表附件**：无按项目特点梳理的指标体系，无指标解释、评分细则、数据来源。
15. **问卷访谈与指标脱节**：未根据修改后的指标体系和方案重新梳理。
16. **缺自评价复核方案**。
17. **格式不规范**：未按委托方（区级绩效评价通知）标准格式撰写。

## 二、合格实施方案必须包含的要素

由上述缺陷反推，一份合格方案应具备以下要素（对照清单逐一核验）：

| 序号 | 要素 | 关键要求 |
|---|---|---|
| 1 | 项目背景及目的 | 分层级（国/省/市/区）背景→实施目的→起始年份→每期资金及实施情况 |
| 2 | 立项依据 | 分点列清各层级依据文件 |
| 3 | 政策项目内容 | 内容、标准、范围、主体、程序、实施周期、当期实施情况（参保/理赔数据） |
| 4 | 项目预算及资金用途 | 财政资金下达文号、下达时间、资金层级 |
| 5 | 资金使用情况 | 支付单位、支付时间、支付程序 |
| 6 | 项目管理 | 聚焦项目本身管理，非部门全部职能 |
| 7 | 利益相关方 | 完整覆盖（含企业、个体等被服务方） |
| 8 | 总体目标与阶段性目标 | 依据项目内容重新梳理，文字表述提炼 |
| 9 | 评价方向与侧重点 | 侧重政策实施效果及后续改善 |
| 10 | 绩效指标体系 | 指标解释、评分细则、数据来源齐备；含项目特色指标 |
| 11 | 样本抽取方案 | 覆盖各类型（核心/扩展/潜在/对比）、筛选方法明确、可实施 |
| 12 | 问卷与访谈设计 | 与指标体系、方案一致 |
| 13 | 质量控制措施 | 精炼实用 |
| 14 | 自评价复核方案 | 必配 |
| 15 | 格式 | 按委托方标准格式 |

## 三、成本预算绩效管理（成本绩效分析）方法模式

### 3.1 总体工作思路（五步主线）

> 明确绩效目标 → 确定业务流程 → 核定投入成本 → 测算财政支出 → 优化管理机制

### 3.2 濮阳"八步工作法"

1. 摊开历史账本
2. 剔除不当因素
3. 开展成本分析
4. 设定成本绩效基线
5. 优化工作流程
6. 核定价格成本
7. 设定绩效标准
8. 提出切实建议

### 3.3 成本要素拆分与实测取数

- **聚焦关键环节**：人均养护面积、长期/季节性用工比例等。
- **一线实测关键运行底数**（为成本分析提供"第一手依据"）：
  - 树木刷白：平均每人5分钟涂白一棵、日涂白96棵；
  - 行道树修剪：平均每人20分钟修剪一棵、每日有效时间7小时。
- **支出拆分**：省科技馆运维经费按能耗费、维修维护费等15个方面拆解，首次制定水费、电费、综合物业费、消防维保费等10项支出预算标准。

### 3.4 定额标准制定路径

- 参照既有标准：省直机关物业费管理办法标准、省级公益性场馆基本运维支出专用预算标准。
- 横向对比：与周边省份科技馆对比。
- 建立分类分档体系、项目配置标准和支出标准（如高中开办费"分类分档"）。

### 3.5 核减逻辑与案例

| 项目 | 核减结果 | 核减率/降幅 |
|---|---|---|
| 濮阳城区绿化养护 | 2025年测算4644万元，较2023年核减2810万元 | 38% |
| 华龙区东北庄园区物业托管 | 285万元 → 152万元 | 46.7% |
| 郑州新建高中开办费 | 每班150万元 → 110万元 | 26.7% |
| 全省（9个项目17.4亿元） | 累计压减预算8762.7万元 | — |

核减逻辑本质：**成本底数实测 → 剔除不当因素 → 对标标准/横向对比 → 重新核定价格 → 设定支出标准**，打破"历史基数"依赖。

### 3.6 试点项目选择原则

- 四原则：**需求迫切、关注度高、数据可得、代表性强**。
- 三类项目：运行维护类（场馆/学校/信息系统运维）、城市运行类（环卫清扫、绿化养护）、业务经费类（高中开办费、医保经办、教师培训）。

## 四、改革方向和最新趋势要点

### 4.1 河南改革"路线图"（三步走）

- **2025年**：成本预算绩效管理工作全省范围稳步推开。
- **2026年**：丰富完善省级操作指引等标准建设，从"一件事"降本增效扩展到"一类事"成本管控。
- **2027年**：建立成本预算绩效管理体制机制，推动其与预算管理深度融合。

### 4.2 改革取向

- **破解历史基数依赖**：针对"成本底数不清、标准偏高、金额固化"问题，与零基预算改革结合，打破支出固化僵化格局。
- **标准先行、精准核算**：把成本分析成果固化为财政支出标准，发挥标准在预算管理中的基础性作用。
- **降本增效聚焦民生**：教育、科技、卫生、行政运行、城市运行等领域。
- **组织模式创新**：郑州"书记项目"（党组书记牵头、跨部门工作组、破信息壁垒、一体化平台）；濮阳引入人大全程监督；"以市带县、互鉴互促"统一路径标准。

### 4.3 全国趋势（同版各地实践）

- **江西**：政府收入绩效管理"末端评价试点"+"全链条闭环试点"双试点，"1+N"政府收入绩效评价体系。
- **山西太原**：零基预算+绩效管理推进财政支出标准体系建设（已出台10项支出标准，动态评估更新机制）。
- **江苏苏州工业园区**：部门自主重点评价，"四个环节备案"+"自主评价有加分"激励机制，构建"评价—反馈—整改—提升"闭环。
- **广西**：预算绩效分类指标体系梳理，导入预算管理一体化系统，推动绩效目标设定由"填空题"向"选择题"转型。
