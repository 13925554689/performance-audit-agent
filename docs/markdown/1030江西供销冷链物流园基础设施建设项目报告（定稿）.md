一、项目概况
1.项目建设背景
为打通农产品城乡流通渠道，助力农民增收致富，坚决打赢
脱贫攻坚战，全力服务乡村振兴战略，江西省委、省政府高度重
视并要求加快建成江西省城乡冷链物流骨干网，明确要求江西省
供销合作社联合社作为全省冷链物流发展牵头单位，加快建设全
省城乡冷链物流骨干网。
按照《预算法》《国务院关于加强地方政府性债务管理的意
见》（国发〔2014〕43 号）等文件，结合江西省建设规划，江西
省人民政府决定通过发行地方政府专项债券方式来实施本项目，
以满足江西省供销集团冷链物流基础设施建设项目的融资需求。
江西省供销集团同步成立江西省供销冷链科技集团有限公司
作为项目投资、建设、运营主体，并在2020 年完成首批9 个项目
签约。根据各子项目建设需求统筹成立全资子公司开展具体项目
建设。项目建成后，由江西省供销冷链科技集团有限公司进行统
一收支管理并归集各项目收益，确保按时足额支付政府专项债资
金本息。

项目规划总用地面积1291.04 亩，规划总建筑面积86.37 万平
方米，建设内容主要为冷库、干仓、中央厨房和配套办公及生活

方米，实际建设39.83 万平方米，比计划多建设8300 平方米。

（二）立项背景
2019 年7 月，中央政治局将城乡冷链物流设施建设列入三大
补短板工程之一推动实施。为促进、规范农业产业发展，国家和
地方陆续发布相关政策、标准支持冷链物流行业的发展。
江西是全国重要的农产品产地，冷链物流潜在需求规模庞大。
因大部分县（市、区）以丘陵、山地等为主，信息技术不强、缺
少完整的冷链物流体系，许多农产品无法卖出去、卖出好价钱。
为打通农产品城乡流通渠道，密切与农民利益联结，助力农民增
收致富，坚决打赢脱贫攻坚战，全力服务乡村振兴战略，江西省
委、省政府高度重视并要求加快建成江西省城乡冷链物流骨干网，
明确要求江西省供销合作社作为全省冷链物流发展牵头单位，加
快建设全省城乡冷链物流骨干网。
江西省供销合作社通过详细、全面的调查研究，根据全省特
色农产品产地和区位特点，按照“一轴、两核、四线、多节点、
全覆盖”的空间布局，提出了分步建设物流体系运营总部和六级
节点农产品冷链物流中心，打造立足江西，对接长三角、粤港澳
大湾区，融入“一带一路”发展战略的现代农产品冷链物流服务
体系的构想。按照这一布局，江西省供销合作社研究制订了《江
西省冷链物流服务乡村振兴实施计划》《江西省城乡冷链物流双
